# Tagshop – Free Unlimited Affiliate Wall Builder

**Live Demo:** https://linkbotlabs.github.io/Linkme/

A simple, no-signup browser tool for affiliate marketers to quickly build and share personalized product showcase pages (walls) with automatic affiliate tagging.

Supports Amazon, Temu, DHgate, AliExpress, Lazada and more.

### Features
- 🔍 **Product Search** – Powered by Google Custom Search (add items with one click)
- 🤖 **AI Chat** – Ask for product ideas, descriptions, or marketing copy (multiple models including GPT-4 variants & streaming Kimi K2)
- 🛒 **My Wall** – Your personal unlimited showcase page
  - Auto-applies your affiliate tags (Amazon `tag`, Temu `aff_id`, DHgate `affid`)
  - Shareable compressed links + QR code (viewers see your tagged products)
  - View-only mode for shared walls
- ✅ **Unlimited items** for everyone (password: `tagshopme` – enter once on My Wall)
- 💰 **Donation optional** – Support via Wise or Buy Me a Coffee to keep it ad-free

### How to Use
1. Go to → https://linkbotlabs.github.io/Linkme/
2. Search for products (or use AI chat for ideas)
3. Click **Add to Wall** on any result
4. Go to **My Wall** (floating button bottom-right)
5. Set your affiliate tags (Amazon, Temu, DHgate) in the 💰 My Affiliate Tags popup
6. Add as many products as you want (unlimited after entering password `tagshopme` once)
7. Click **🔗 Share Wall** → copy link or QR code
8. Share anywhere – viewers see your curated products with your affiliate links applied

Shared walls are view-only and use the sharer’s affiliate tags.

### Tech Stack
- Pure HTML + CSS + JavaScript (no backend)
- Hosted on GitHub Pages
- Libraries: Puter.ai (free models), LZString (compressed sharing), QRCode.js
- Storage: Browser localStorage (your wall & tags stay on your device)
